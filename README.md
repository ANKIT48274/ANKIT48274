## About

I test applications and networks the way an attacker would, then write the result so that an
engineering team can fix it. My work covers web applications, APIs, internal networks and Active
Directory, and I build AI-assisted tooling for the parts of that work that are repetitive:
reconnaissance, evidence handling and report assembly.

I hold the HTB Certified Penetration Testing Specialist (CPTS) and the HTB Certified Offensive AI
Expert (COAE) certifications, and I publish the tools and notes I use in this account.
